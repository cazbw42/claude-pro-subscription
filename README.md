## 八、几点防封号的小建议

封号这事没有 100% 的保险，但有几件事做了确实能降低概率：

- **IP 尽量稳定**：不要今天日本、明天美国、后天香港地乱跳，Anthropic 的风控对"IP 漂移"很敏感。
- **别用被滥用的节点**：机场共享节点往往已经被打标，用的人越多越危险，有条件上独享或住宅 IP。
- **注册就用真实邮箱**：Gmail、Outlook 这类大厂邮箱比临时邮箱稳得多，临时邮箱很容易被识别为风险账号。
- **登录设备别太杂**：一台主力设备 + 一个稳定浏览器，比天天换设备换浏览器安全。
- **使用行为别太"机器人"**：纯 API 式的高频调用、批量请求，比正常对话更容易被风控盯上。
- **充值后第一时间改密、开 2FA**：哪怕你走的是只需 Organization ID 的代充，养成这个习惯没坏处。
